EditMeText non ha connessione a Internet, non ha account e non raccoglie alcun dato. I tuoi file esistono solo dove scegli di conservarli.

Cosa viene salvato

Il testo che apri o crei esiste in memoria solo mentre lo modifichi; il salvataggio lo scrive nella posizione scelta nel selettore di file del sistema (su questo iPhone, in iCloud Drive o presso un altro provider di file). Per evitare perdite, l’app conserva una bozza locale pochi secondi dopo che smetti di scrivere e la elimina automaticamente quando il file è stato scritto. I file aperti di recente vengono ricordati solo come segnalibro di sistema per riaprirli; il loro contenuto non viene copiato.

Cosa lascia il telefono

Solo ciò che fai tu: salvare in una posizione a tua scelta come iCloud Drive, oppure condividere un TXT o un PDF con il foglio di condivisione del sistema. L’app di per sé non effettua alcuna richiesta di rete. Non c’è nessun server e nessun account.

Conversione dei formati

La conversione di file PDF, Word, Pages, RTF, HTML e OpenDocument in testo semplice avviene interamente sul tuo telefono. Nulla viene caricato e nessuna terza parte è coinvolta. Il file originale non viene mai modificato.

Acquisto in-app

La versione completa è un acquisto una tantum gestito dall’App Store di Apple. Sappiamo solo se questo dispositivo l’ha acquistata; non vediamo mai il tuo nome, il metodo di pagamento o altre informazioni personali. Anche il ripristino dell’acquisto passa solo da Apple.

Cosa non facciamo

Nessun SDK di analisi, segnalazione crash o pubblicità. Nessun accesso a contatti, foto o posizione. Nessun servizio di IA. Nessun tracciamento.

Autorizzazioni usate

File: per aprire e salvare i file che scegli. L’accesso è limitato esattamente al file o alla cartella che hai selezionato. Non serve nessun’altra autorizzazione di sistema.

Eliminazione

Eliminando l’app vengono rimosse le bozze locali e l’elenco dei documenti recenti. Il contenuto salvato nei file resta dov’è e non viene toccato. Puoi anche svuotare l’elenco dei documenti recenti in qualsiasi momento nelle Impostazioni.

Minori

Questa app non è rivolta a minori di 13 anni e non raccoglie informazioni sui minori.
