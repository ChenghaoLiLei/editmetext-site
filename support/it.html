Creare e aprire

Nella schermata iniziale tocca “Nuovo documento” per partire da zero, oppure “Apri file” per scegliere un file da questo iPhone, da iCloud Drive o da un’altra posizione con il selettore di file del sistema. Nell’app File puoi anche tenere premuto un file e scegliere EditMeText in “Apri con”.

Formati supportati

I file di testo come TXT, Markdown, CSV e JSON si modificano direttamente e vengono riscritti nel file originale. PDF, Word (.docx), Pages, RTF, HTML e OpenDocument vengono prima convertiti in testo semplice; il salvataggio crea un nuovo file TXT e lascia intatto l’originale. Il vecchio formato .doc non è ancora supportato e il testo nelle tabelle di Pages non può essere letto.

Salva e Salva con nome

“Salva” riscrive nel file originale. Il primo salvataggio di un nuovo documento e “Salva con nome” ti fanno prima scegliere una cartella, poi confermare il nome del file; se esiste già un file con quel nome ti viene chiesto se rinominare o sovrascrivere. Se il file è stato modificato altrove, l’app ti avvisa e propone Salva con nome o Sovrascrivi invece di sostituire in silenzio la versione di qualcun altro.

Recupero delle bozze

Pochi secondi dopo che smetti di scrivere, il testo che stai modificando viene salvato come bozza locale. Se l’app viene chiusa o il telefono si scarica, lo ritrovi in “Bozze non salvate” nella schermata iniziale. La riga di stato “Bozza salvata automaticamente” significa che non è ancora stata scritta nel file; “Salvato nel file” compare solo dopo una scrittura riuscita.

Esportare in PDF

Tocca il pulsante “PDF” in basso per vedere l’anteprima dell’impaginazione A4, poi salvala come file PDF o condividila direttamente. Il testo del PDF può essere selezionato e cercato.

Codifica

I vecchi file che non sono in UTF-8 (per esempio GB 18030, Big5 o Shift JIS) ti chiedono di scegliere una codifica con anteprima prima dell’apertura. Al salvataggio i file vengono scritti in UTF-8; un eventuale BOM nell’originale viene mantenuto.

Versione completa

La conversione di altri formati in testo semplice è gratuita per 10 file; dopo serve un acquisto una tantum della versione completa. Non c’è abbonamento. Dopo aver cambiato telefono o reinstallato, tocca “Ripristina acquisto” nelle Impostazioni. Creare, modificare, salvare TXT e Markdown ed esportare in PDF restano gratuiti per sempre.

Cambiare lingua

Impostazioni → Lingua dell’interfaccia: passa tra 25 lingue in qualsiasi momento, indipendentemente dalla lingua di sistema del telefono.

Un file non si apre?

Nell’app File tieni premuto il file e scegli “Info” per vedere il tipo reale. Un documento creato con Pages è un file Pages anche se il nome finisce in .txt, e ora si può aprire direttamente. Un vecchio file Word .doc va prima salvato come .docx in Word o Pages. Un PDF che è solo un’immagine scansionata non contiene testo da estrarre.
