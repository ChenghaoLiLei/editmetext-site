Create and open

On the home screen, tap “New Document” to start from scratch, or “Open File” to pick a file from this iPhone, iCloud Drive or another location with the system file picker. In the Files app you can also long-press a file and choose EditMeText under “Open With”.

Supported formats

Text files such as TXT, Markdown, CSV and JSON are edited directly and written back to the original file. PDF, Word (.docx), Pages, RTF, HTML and OpenDocument are converted to plain text first; saving creates a new TXT file and leaves the original untouched. The legacy .doc format is not supported yet, and text inside Pages tables cannot be read.

Save and Save As

“Save” writes back to the original file. The first save of a new document and “Save As” first let you choose a folder, then confirm the file name; if a file with that name exists you are asked whether to rename or overwrite. If the file was changed elsewhere, the app warns you and offers Save As or Overwrite instead of silently replacing someone else’s version.

Draft recovery

A few seconds after you stop typing, the text you are editing is saved as a local draft. If the app is closed or the phone runs out of battery, you will find it under “Unsaved Drafts” on the home screen. The status line “Draft auto-saved” means it has not been written to the file yet; “Saved to file” appears only after a successful write.

Export PDF

Tap the “PDF” button at the bottom to preview the A4 layout, then save it as a PDF file or share it directly. Text in the PDF can be selected and searched.

Encoding

Old files that are not UTF-8 (for example GB 18030, Big5 or Shift JIS) ask you to pick an encoding with a preview before opening. On save, files are written as UTF-8; a BOM in the original is kept.

Full Version

Converting other formats to plain text is free for 10 files; after that a one-time purchase of the Full Version is required. There is no subscription. After switching phones or reinstalling, tap “Restore Purchase” in Settings. Creating, editing, saving TXT and Markdown and exporting PDF stay free forever.

Change language

Settings → Interface Language: switch between 25 languages at any time, independent of the phone’s system language.

A file won’t open?

In the Files app, long-press the file and choose Get Info to see its real type. A document created in Pages is a Pages file even if its name ends in .txt, and can now be opened directly. For a legacy Word .doc file, save it as .docx in Word or Pages first. A PDF that is only a scanned image has no text to extract.
